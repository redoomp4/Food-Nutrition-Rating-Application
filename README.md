# 🍔 Ngilers: Food Nutrition Rating Application

Aplikasi desktop berbasis **Python & PyQt5** yang dirancang untuk membantu pengguna memantau kandungan nutrisi dan kalori makanan secara interaktif. Proyek ini dikembangkan sebagai bagian dari tugas mata kuliah Algoritma Pemrograman.

## ✨ Fitur Utama
*   **Modern Sidebar Navigation**: Navigasi responsif dengan mode ikon dan teks.
*   **Nutrient Dashboard**: Visualisasi kartu makanan dengan informasi nutrisi lengkap.
*   **Responsive Top Bar**: Judul aplikasi yang selalu presisi di tengah layar (Absolute Centering).
*   **Interactive About Me**: Profil pengembang dengan tautan langsung ke LinkedIn, Instagram, dan YouTube.
*   **Dynamic UI Scaling**: Tampilan yang dioptimalkan untuk berbagai resolusi layar.

## 🛠️ Teknologi yang Digunakan
*   **Language**: Python 3.x
*   **GUI Framework**: PyQt5
*   **Design Tools**: Qt Designer
*   **Styling**: Qt Style Sheets (QSS)

## 🚀 Cara Menjalankan
1.  Pastikan Anda sudah menginstal Python dan PyQt5:
    ```bash
    pip install PyQt5
    ```
2.  Clone repository ini:
    ```bash
    git clone https://github.com/redoomp4/Food-Nutrition-Rating-Application.git
    ```
3.  Masuk ke direktori proyek:
    ```bash
    cd Food-Nutrition-Rating-Application
    ```
4.  Jalankan aplikasi:
    ```bash
    python main.py
    ```
